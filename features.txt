CyclogenAI — FEATURES LIST
========================

1. LANDING PAGE
   - Hero section with headline "Train smarter. Race harder."
   - Animated gradient background (orange-black theme)
   - Stats bar: 685+ Activities, 53K+ KM Analyzed, 12 Race Podiums, 4.9 Avg Rating

   - Performance score

    - OAuth 2.0 authorization flow

16. BACKEND API
    - NestJS server on localhost:3001
    - MongoDB Atlas database
    - Auth endpoints: login, signup, password management
    - CRUD endpoints: activities, races, expenses, gear
    - Stats aggregation
    - Training context management (month, week, pre-race plans)
    - Strava token management and sync
    - AI analysis endpoint
    - User management

    - Periodization models: Build, Base, Peak, Taper, Recovery
    - Goal feasibility assessment
    - Structured workout planning
    - intervals.icu integration
